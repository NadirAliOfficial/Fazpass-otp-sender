# Fazpass OTP Sender

A Python script to send OTP (One-Time Password) messages using the Fazpass API.

## Features
- Send OTP via Fazpass API
- Configurable sender and message template
- Simple CLI interface

## Requirements
```
pip install requests
```

## Usage
```bash
python send_otp.py --phone +62XXXXXXXXXX
```

## Configuration
Set your Fazpass API key in `config.py`.
